## 自动检查

需要 Node.js 24：

```bash
npm ci --registry=https://registry.npmjs.org/
npm run check
npx playwright install --with-deps chromium
npm run test:browser
```

GitHub Actions 使用同样顺序。浏览器测试运行项目控制的模拟播放器页面，不需要 B 站账号；Windows 默认使用已安装的无头 Edge，其他平台使用 Chromium，可用 `PW_CHANNEL` 指定测试通道。

主要覆盖：

- **配置：** 数值边界、旧设置回退、实例间隔离、写入失败。
- **存储：** 事务中止、失败恢复、重复 / 并发迁移、图片分离、备份校验与去重。
- **播放器：** BV 多 P / EP 来源、等待就绪、同容器切源、Canvas 时间、黑边几何和资源清理。
- **复习本：** 串行保存、失败草稿、查询乱序、回听前保存、错源不播放、焦点、懒加载、分页和导入确认。
- **浏览器集成：** 以实际测试代码和运行报告为准；计划场景不计为通过。

### 失败场景

- 强制数据库打开失败、事务 abort、配额不足：不能显示保存成功，迁移源可恢复。
- 错误 schema、来源 URL、图片格式或超限数据：写入前拒绝，已有数据不被覆盖。
- 导入最多 5,000 条、单图 10 MiB、元数据与解码图片合计 100 MiB；JSON 文件超过 150 MiB 时读文本前拒绝。
- 截图或自动播放受限：明确失败 / 降级，不保存虚假时间。旧卡片缺来源时不猜测地址。
- 完整备份包含收藏数据，不包含设置；两者分别验证。

## 性能采样计划

固定浏览器、机器与窗口，用 100 / 1,000 / 5,000 条固定样本，记录首屏可交互、翻页、输入、截图与内存峰值，并注明图片大小、样本和运行次数。

1,000 条下首屏 300 ms 可作为待校准目标，**不是当前实测成绩或保证**。分页与懒加载逻辑测试不能代替真实性能采样。
