# Bilibili 剧集双语字幕羽化遮罩与生词本 (看剧学英语)

专为在 B 站观看美剧（如《老友记》）及各类英文视频学习英语而设计的一站式工具。不仅提供了**对标“沉浸式翻译”的无框羽化中文字幕模糊**与**极速盲调**，更打造了**一键截取高清剧照 + 精准时间戳秒跳 + 纯净侧边生词复习抽屉**的完整学习闭环！

---

## 🌟 核心特色 (v2.2.0 终极发布版)

1. **对标“沉浸式翻译”：无框羽化光学模糊**
   - 彻底移除了黑色底色，使用纯净透明背景 + GPU 硬件加速的 `backdrop-filter: blur(14px)`。
   - 采用 CSS 双向渐变羽化（`-webkit-mask-image` 与 `source-in` 交叉合成），遮罩四周边缘自然融入视频画面。中文字幕如同高斯模糊般自然散焦，画面整体通透和谐。
2. **`Alt + 鼠标滚轮` 极速盲调（修复音量与可视化）**
   - 按住 `Alt` 并滑动鼠标滚轮，以 0.5% 精度上下平滑微调遮罩位置。
   - 采用全局事件捕获阶段拦截，**绝不干扰 B 站原生音量**。
   - 滑动滚轮时自动显示清爽的青色虚线轨迹框，松手 0.6 秒自动淡出恢复羽化。
3. **右上角控制条呼吸自动隐形（Auto-Hide，纯影院沉浸感）**
   - 鼠标在播放器内静止超过 2.5 秒，右上角控制条自动平滑淡出隐形；晃动鼠标即刻淡入浮现，观影画面 100% 纯净无遮挡。
4. **一键快照采集（0 打断收藏）**
   - 按 `Alt + S` 或单按 `S`，瞬时截取原画帧高清剧照并绑定精准时间戳（如 `07:57`）。
5. **侧边生词抽屉复习（Review Drawer）**
   - 按 `Alt + B` 唤出生词本抽屉，点击时间戳**秒跳回原视频对应帧播放**，支持随手记笔记与一键导出 Markdown。
6. **工业级 IndexedDB 本地数据库**
   - 突破传统 localStorage 的 5MB 限制，轻松存储几千张剧照，永不爆仓崩溃，数据自动平移。
7. **新手开箱 4 秒引导气泡**
   - 首次安装打开视频时，屏幕中央浮现轻量引导气泡，4 秒后自动淡出并永久不再打扰。

## ⌨️ 快捷键与操作速查表

| 操作 / 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **按住 `Alt` + 滑动滚轮** | 垂直位置盲调 | 0.5% 精度微调，显示青色轨迹框，**不干扰音量** |
| **`Alt + S` 或 `S`** | 一键快照收藏画面 | 瞬时抓取高清剧照 + 记录时间戳（亦可点右上角按钮） |
| **`Alt + B` 或 `B`** | 打开/关闭生词本 | 右侧滑出半透明复习抽屉，点击时间戳可秒跳视频帧 |
| **鼠标悬停 (Hover)** | 瞬时偷瞄中文 | 移入中文字幕区即刻看清，移出恢复羽化散焦 |
| **长按 `Alt`** | 瞬时偷瞄中文 | 键盘手不离键，按住偷瞄，松手恢复羽化散焦 |
| **`Alt + Z` 或 `Shift + Z`** | 切换拉伸编辑模式 | 进入 8 手柄自由拖拽/拉伸模式（双击遮罩亦可） |
| **`Alt + C` 或 `Shift + C`** | 开关遮罩 | 临时隐藏或重新开启遮罩 |

## 🚀 安装与升级指南

1. 打开油猴（Tampermonkey / ScriptCat）管理面板，点击编辑已有脚本。
2. 将 [`bilibili-caption-blur-mask.user.js`](./bilibili-caption-blur-mask.user.js) 的代码**全部覆盖粘贴**并保存（**Ctrl + S**）。
3. 刷新 B 站《老友记》播放页即可享受极速版！
