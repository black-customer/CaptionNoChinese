# v2.4.0 — 可靠收藏与场景复习

本版修复旧数据迁移、保存成功反馈和跨集回放，并加入片段循环、检索与可恢复备份。

## 主要更新

- IndexedDB 事务提交后才显示保存成功；失败清楚提示。历史迁移保留原始副本、提交标记幂等，不覆盖后续编辑或恢复已删除卡片。
- 标题和笔记以文本呈现；截图独立存储，列表分页、图片按需加载。
- 收藏保留 BV/EP/分 P 来源；先返回正确视频，再定位。Canvas 截图与播放时钟分离。
- 遮罩跟随真实画面、切视频与全屏；快捷键避开编辑区、忽略重复触发，滚轮限定播放器内。
- 搜索、标签、复习状态、答案隐藏、删除撤销、编辑草稿与失败重试。
- 收藏点前后区间循环，可调次数、间隔、倍速；结束恢复当前视频循环前的进度。
- 全量 JSON 备份、导入预览与去重；当前筛选导出可离线阅读的 HTML。
- 界面显示 v2.4.0，设置与帮助可随时打开；保持单个用户脚本安装方式。

## 升级

安装附件中的 `bilibili-caption-blur-mask.user.js`，或使用仓库首页的安装链接。脚本保持原名称与命名空间，更新已有条目；更新地址指向 GitHub。升级后刷新视频页。

## 已知边界

- 收藏属于本机浏览器数据，请定期备份；不保证无限容量或永久保存。
- 截图为最大宽度 960px、质量 0.85 的 JPEG；不支持截图时可保存可靠的来源时间书签。
- JSON 导入每次最多 5,000 条、单图 10MiB、数据合计 100MiB；不覆盖已有 ID；备份不包含遮罩设置。
- 旧卡片缺少来源时不会猜测分集；跨视频循环先完成导航，再点击开始循环。
- 本版没有 OCR、自动翻译、账号或云同步。
