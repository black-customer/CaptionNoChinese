# Bilibili 中文字幕遮罩与场景复习本

在桌面 B 站看双语视频时遮住中文，留下想再听的场景，再回到正确视频复听。**当前版本：v2.4.0。**

适用于内嵌双语字幕：遮罩按视频画面的实际区域定位，支持临时查看中文、截图收藏、笔记和片段循环。脚本不自动识别或翻译字幕。

[安装 / 更新脚本](https://raw.githubusercontent.com/black-customer/CaptionNoChinese/main/bilibili-caption-blur-mask.user.js) · [版本记录](CHANGELOG.md) · [验收与已知边界](docs/ACCEPTANCE.md) · [历史评审](docs/REVIEW_AND_ROADMAP.md)

## 安装与更新

1. 在桌面浏览器安装并启用 [Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/)，按管理器提示完成扩展权限设置。
2. 打开上方的 **安装 / 更新脚本** 链接，在脚本管理器页面确认安装。
3. 打开或刷新 B 站视频页，使用播放器内的收藏、复习本、遮罩和设置入口。

如果链接直接显示代码，可在管理器中新建脚本，将 [`bilibili-caption-blur-mask.user.js`](bilibili-caption-blur-mask.user.js) 的完整内容粘贴进去并保存。失败时先检查管理器是否启用、是否获准在 B 站运行。

脚本的更新地址指向本仓库 `main` 分支。安装后由管理器按自身设置检查更新，也可在管理器中手动检查。升级时覆盖原条目，避免同时启用两个版本。大量收藏建议先使用 **备份全部**。

浏览器兼容性以 [验收记录](docs/ACCEPTANCE.md) 为准；模拟播放器测试不能替代真实 B 站和脚本管理器验收。

## 怎么用

1. **遮住中文：** 选择模糊或实色模式，调整遮罩位置、大小与模糊强度。
2. **需要时查看：** 鼠标移入遮罩或按住 `Alt` 临时显示中文，移开或松键后恢复。
3. **留下场景：** 按 `Alt + S` 收藏当前画面和时间，或点击收藏按钮。
4. **回到原片段：** 在复习本点击时间按钮回听；跨集卡片会返回自己的来源视频。
5. **多听几遍：** 设置片段前后范围、重复次数、间隔和倍速，开始 A–B 循环；停止后恢复当前视频开始循环前的进度。跨视频时先返回来源，页面就绪后再点一次循环。
6. **记下理解：** 填写笔记、标签，标记“待复习 / 仍不会 / 已掌握”；也可以先隐藏笔记答案，回忆后再揭示。

复习本支持搜索笔记、标题和标签，筛选当前剧集或全部收藏，每页显示 30 条。

### 快捷键

| 操作 | 功能 |
|---|---|
| `Alt + S`，或启用单键后的 `S` | 收藏场景 |
| `Alt + B`，或启用单键后的 `B` | 开关复习本 |
| `Alt + C` / `Shift + C` | 开关遮罩 |
| `Alt + Z` / `Shift + Z`，或双击遮罩 | 遮罩编辑 |
| 播放器内 `Alt + 滚轮` | 上下微调 |
| 鼠标移入遮罩，或按住 `Alt` | 临时查看中文 |
| `Escape` | 关闭当前界面或结束相应编辑状态 |

可在设置中关闭 S / B 单键，保留组合键。输入框内不触发收藏等快捷操作；长按操作键不会连续创建卡片。具体范围和快捷键也可随时从 **操作帮助** 查看。

## v2.4.0 的改进

- **可靠保存：** 事务完成后才算成功，失败明确提示；历史迁移可重试，不重复覆盖新笔记或恢复已删除卡片。
- **准确来源：** 收藏记录视频、分集 / 分 P 和时间；Canvas 截图从相应播放控制器读取时间。
- **播放器适配：** 遮罩考虑实际画面与黑边，处理容器变化、编辑和全屏状态。
- **日常复习：** 筛选分页、标签、状态、答案隐藏、回听提前量和 A–B 循环。
- **草稿与撤销：** 输入后延迟保存，重绘保留编辑，失败可重试；删除可撤销最近一次操作。
- **安全文本：** 标题、笔记与标签按普通文字显示，不将输入解释成 HTML。
- **备份与阅读：** JSON 恢复前预览并去重；HTML 阅读版包含图片、笔记和来源链接。

## 保存、备份与限制

收藏和图片保存在当前站点、当前浏览器配置中的 IndexedDB；设置使用脚本管理器存储，无法使用时按支持情况回退到本地存储。**清理站点数据、删除浏览器配置或存储空间不足可能影响收藏。** 本地存储不是无限容量，也不保证永久保存。

| 操作 | 范围 | 用途 |
|---|---|---|
| **备份全部** | 全部剧集的收藏、笔记、标签、状态和截图 | JSON 文件，可通过“导入备份”恢复 |
| **导出阅读版** | 当前范围、关键词和状态筛选结果 | 可离线打开的 HTML，用于阅读，不是恢复格式 |

导入先显示总数、新增数和已存在数量，再由用户确认。**同 ID 的已有收藏保留，默认跳过，不覆盖。** 完整备份指收藏数据，不包含遮罩位置等脚本设置。

导入每次最多 **5,000 条**，单图最多 **10 MiB**，元数据与解码图片合计最多 **100 MiB**。页面在读取前拒绝超过 **150 MiB** 的 JSON 文件。只接受支持的备份结构与 JPEG、PNG、WebP 图片。

截图默认压缩为 **最大宽度 960 px 的 JPEG（质量 0.85）**，不是原画无损截图。截图能力受播放器、跨域限制、受保护画面和媒体就绪状态影响；失败时按界面提示处理。

其他边界：

- 旧卡片缺可靠来源时，无法凭标题补出准确分集地址。
- 整季归组依赖可靠季信息；取不到时按分集归组，普通多 P 视频按 BV 分组。
- 网页全屏、播放器原生全屏与 F11 不同。媒体元素自身全屏无法承载任意网页界面，需要明确降级。
- 当前没有账号、跨设备同步、OCR、自动翻译、词典或间隔复习算法。
- 脚本没有主动上传收藏或笔记的功能；更新脚本与打开来源视频仍需要网络。

## 开发

需要 **Node.js 24**，使用锁文件安装依赖：

```bash
npm ci --registry=https://registry.npmjs.org/
npm run test           # 单元与集成夹具测试
npm run build          # 构建单文件 userscript
npm run check          # 测试、构建、产物语法检查
npx playwright install chromium
npm run test:browser   # 本地模拟播放器浏览器测试
npm run preview       # 本地预览服务
```

开发源文件在 `src/`，根目录 `.user.js` 是构建产物。修改源码后重新构建，不要只编辑生成文件。用户安装运行脚本不需要 Node.js。

复现步骤和实测范围见 [验收文档](docs/ACCEPTANCE.md)。故障报告请附浏览器、脚本管理器、脚本版本、页面类型、复现步骤与报错；不要公开私人备份。
