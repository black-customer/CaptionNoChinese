# Bilibili 中文字幕遮罩与场景记录库 v3.1.1

在桌面 B 站看内嵌双语字幕时遮住中文，按 `C` 留下想再听的场景。看完一集，再集中回听、写备注和导出。

本版修复点击播放器或工具栏后快捷键失灵，记录提示移入播放器，空结果会在记录库提示。

[安装 / 更新脚本](https://raw.githubusercontent.com/black-customer/CaptionNoChinese/main/bilibili-caption-blur-mask.user.js) · [版本记录](CHANGELOG.md) · [验收与已知边界](docs/ACCEPTANCE.md)

## 安装与更新

1. 在桌面浏览器启用 Tampermonkey 或 ScriptCat，并按管理器提示授予用户脚本运行权限。
2. 打开上方的安装链接，在脚本管理器中确认安装。若浏览器直接显示代码，可在管理器中新建脚本并粘贴完整的 [单文件脚本](bilibili-caption-blur-mask.user.js)。
3. 打开或刷新 B 站视频页。鼠标移入播放器，右上区域会出现浅色工具栏。点击版本号进入设置。

更新地址指向仓库的 `main` 分支，自动检查频率由脚本管理器决定。已有用户可覆盖更新原脚本条目。

## 看剧和整理

1. 选择羽化模糊或不透明遮挡。按 `Alt + Z` 拖动或拉伸遮罩，完成后再次按键锁定。位置按剧集保存，在播放器内按 `Alt + 滚轮` 可微调高度。
2. 播放时按 `C` 或点「记录」。脚本在后台保存画面、视频时间与剧集来源，成功后顶部提示约 1.6 秒。截图受限时，提示会注明只保存了时间和来源。
3. 看完按 `Alt + B` 打开记录库。可切换「当前本集」「当前整部剧」「全部记录」，也可按剧集标题、分集标题或备注搜索。工具栏显示当前整部剧的记录数。
4. 点击时间回到来源，并提前 2 秒播放。填写备注后会自动保存，保存失败时可在当前页面重试。删除后可撤销最近一次删除。

| 操作 | 默认快捷键 |
| --- | --- |
| 一键记录此句 | `C` |
| 开关遮罩 | `Alt + A` |
| 遮罩位置调节 | `Alt + Z` |
| 开关记录库 | `Alt + B` |
| 临时查看中文 | 按住 `Alt` 或将鼠标移到遮罩上 |

五项快捷键都可在设置中录入、禁用或恢复默认，保存时会检查冲突。操作帮助显示当前键位。评论区、备注和设置中会暂停全局快捷键。焦点停在播放器控件或工具栏按钮上时，只有与当前控件自身操作冲突的键位才会让位。

v2.5.0 设置中保存的快捷键若仍是默认配置，升级后会使用 `C`、`Alt + A` 等新默认键。已自定义的键位继续生效。

## 导出和恢复

三个导出按钮使用当前选定范围和搜索词。筛选结果为空时会提示没有记录可导出。要完整备份，选择「全部记录」并清空搜索词。

| 格式 | 内容和用途 |
| --- | --- |
| JSON | 元数据、备注、Base64 截图和时间直达链接。可在「导入备份」中预览后恢复，已有同 ID 记录会保留。 |
| Markdown | 按剧集和分集分组，分集内按视频时间排序。包含直达链接、已填备注和本地记录时间（`YYYY-MM-DD HH:mm`）。 |
| HTML | 单文件离线查看截图和备注。打开原片段链接时需要网络。 |

数据保存在当前站点的 IndexedDB 中，受浏览器配额和站点数据清理影响。备份包含记录，遮罩和快捷键设置由脚本管理器单独保存。导入上限为 5,000 条、单张图片 10 MiB、元数据与解码图片总计 100 MiB。

v3.0.0 移除了到期排期、复习会话、自评、隐藏答案和 A–B 循环。原数据库和旧 JSON 备份仍可读取，历史标签及排期字段随 JSON 保留。旧记录缺少有效视频来源时，仍可查看备注或图片，可用的直达链接以记录中的来源为准。

## 开发

需要 Node.js 24。Windows 浏览器测试默认使用已安装的 Edge，其他平台使用 Chromium。

```bash
npm ci
npm run check
npx playwright install chromium # Windows 默认使用已安装的 Edge
npm run test:browser
npm run preview
```

修改 `src/` 后使用构建脚本同步生成根目录的 `.user.js` 与 `.meta.js`。背景资料见 [历史评审](docs/REVIEW_AND_ROADMAP.md)。项目采用 [MIT License](LICENSE)。


## 同步到本机英语学习器

在桌面英语学习器设置中获取配对码。打开脚本的设置，填写本机 HTTP 地址（默认
`http://127.0.0.1:8765`），选择「输入配对码」并测试连接。记录库的「发送到本机学习器」
会发送当前范围内未同步的场景和后来补写的备注。桌面端只更新待提炼场景的备注。
若希望在按下记录键后自动发送，可勾选「记录后自动发送」
并保存。连接失败时场景仍留在本地，可手动重试，或用 JSON 备份导入桌面端。
